## v0.8.0 — Стабильный релиз

### ✨ Новое
- Умный календарь с выбором года/месяца/дня (русские названия месяцев)
- Динамический список дней (28/29/30/31 + високосные годы)
- Группировка записей по приёмам пищи с эмодзи-метками
- Копирование дня и вставка на другую дату
- Шаблоны приёмов пищи (сохранение / загрузка / удаление)
- Заглушка для пустых дней («📭 В этот день записей нет»)

### 🛠️ Улучшения
- Суммирование граммов при повторном добавлении одного продукта
- Строгая валидация полей целей (только цифры, цифровая клавиатура)
- Полная адаптация тёмной темы (ComboBox, диалоги, разделители)
- Отображение КБЖУ в списке продуктов и записей дневника
- Сортировка записей по логическому порядку дня (не по времени добавления)

### 🐛 Исправления
- Сдвиг дат на -1 день из-за UTC-конвертации
- Баг `detailLoader is not defined`
- Нулевые значения БЖУ в списке записей
- Некорректное отображение заголовков групп («3 точки»)
- Возможность копирования записей в будущее (заблокировано)

### 💾 Данные
- Экспорт/импорт CSV с идемпотентностью (обновление вместо дублей)
- Автоопределение минимального года по первой записи в БД
- Очистка дублей продуктов и кавычек в названиях
