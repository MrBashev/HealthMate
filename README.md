## 📖 Описание проекта
**HealthMate** — это мобильное приложение, разработанное для поддержки пользователей в ведении здорового образа жизни. Основная идея проекта — сделать отслеживание питания и активности максимально простым и доступным в любой ситуации, даже без подключения к интернету.

Приложение позволяет:
*   📝 **Вести дневник питания:** Быстрая запись приемов пищи в любое время.
*   💾 **Работать офлайн:** Все данные сохраняются локально на устройстве, что обеспечивает конфиденциальность и доступность.
*   📊 **Анализировать привычки:** Визуализация прогресса без сложной статистики.
*   🛡️ **Защищать данные:** Использование локальной базы данных минимизирует риски утечки личной информации.

## 🎯 Почему мобильное приложение?
1.  **Всегда под рукой:** Пользователь может записать еду сразу после приема, не полагаясь на память.
2.  **Снижение барьеров:** Удобный интерфейс повышает мотивацию следовать плану питания.
3.  **Конфиденциальность:** Локальное хранение данных (SQLite) соответствует принципам безопасности персональной информации о здоровье.

## 🛠 Технологический стек
Проект разработан с использованием кроссплатформенного подхода для обеспечения совместимости:
*   **Язык программирования:** C++ (Core Logic)
*   **Фреймворк:** Qt 6 (Qt Quick / QML для интерфейса)
*   **База данных:** SQLite (локальное хранение на устройстве)
*   **Среда разработки:** Qt Creator
*   **Целевые платформы:** Android (мин. версия API__), iOS (планируется)

## 🚀 Как запустить проект
Для сборки проекта вам потребуется настроенное окружение Qt для мобильной разработки:

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-никнейм/репозиторий.git
    ```
2.  Откройте проект `HealthMate.pro` (или `CMakeLists.txt`) в Qt Creator.
3.  Выберите кит (Kit) для Android или Desktop (для тестирования).
4.  Нажмите **Run** (Ctrl+R).

> **Примечание:** Для сборки под Android необходимо наличие настроенных Android SDK, NDK и JDK.
